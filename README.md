## 🎯 Course Focus & Key Themes

This repository covers key software design principles and architectural patterns throughout the semester, including:

- **Domain Modeling & Conceptual Classes:** Bridging the gap between real-world requirements and software representations.
- **Object-Oriented Analysis & Design (OOAD):** Applying encapsulation, abstraction, inheritance, and polymorphism to complex systems.
- **Invented Software Objects (Pure Fabrication):** Designing service, coordinator, and validator abstractions that enforce business rules without domain bloating.
- **Unified Modeling Language (UML):** Constructing structural diagrams (Class, Object, Package, Component) and behavioral diagrams (Use Case, Sequence, Activity, State Machine).
- **SOLID Design Principles:** Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, and Dependency Inversion.
- **Architectural & Design Patterns:** GoF Creational, Structural, and Behavioral patterns alongside architectural styles (Layered, Microservices, Event-Driven, MVC).
